## 🚀 Latest Project

### **SavApp – Post-Sale Service Management**
A full-stack web application for managing client complaints, technical interventions, and spare parts for a sanitary and central heating company.  

**Tech Stack:**  
- **Frontend:** Blazor  
- **Backend:** ASP.NET Core WebAPI, Entity Framework Core  
- **Database:** SQL Server  
- **Features:**  
  - Client account management & complaint submission  
  - Intervention tracking, warranty checks & fee calculation  
  - Spare parts management  

**GitHub:** [SavApp Repository](https://github.com/wassimhamdi2/SavApp)
